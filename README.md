# GhostStock — AI-Powered Inventory Mismatch Detection

## Overview
GhostStock is a Python-based inventory monitoring application designed to identify unusual stock patterns across multiple warehouse zones using anomaly detection.

## Features
- Inventory monitoring across warehouse zones
- Isolation Forest-based anomaly detection
- Product-level inventory insights
- Interactive dashboard with Streamlit and Plotly
- Data analysis using Pandas

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn

## How to Run
1. Clone or download this repository.
2. Install the required dependencies.
3. Run the application using:

`streamlit run app.py`

## Purpose
The project demonstrates inventory data analysis and anomaly detection through an interactive dashboard.
